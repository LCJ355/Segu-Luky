# Referencia externa

`CHATGPT/MotoGuardV1` es una propuesta externa de prototipo de grabacion de
sensores. No forma parte del codigo de Segu-Luky ni se compila en la app.

Se conserva aqui como referencia para documentar que ideas se evaluaron y cuales
se incorporaron a la linea 1.7s:

- perfil de soporte del movil;
- calibracion con tasa proporcional a la velocidad;
- sensores y columnas de CSV mas ricas.

No se adoptaron sus umbrales fijos de anomalia, el muestreo fijo de 100 Hz, el
servicio `START_NOT_STICKY` ni el modelo de escritura por muestra.
