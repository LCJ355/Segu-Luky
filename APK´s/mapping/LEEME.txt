MAPPING DE R8 - Segu-Luky
=========================

Que es
------
Un `mapping.txt` es el mapa de ofuscacion que genera R8 al compilar la release.
Sin el, las trazas de fallo de la app publicada muestran nombres como
`a.b.c(SourceFile:1)` y no se pueden diagnosticar.

Aqui se guarda uno comprimido por cada version publicada:

    Segu-Luky-1.55s-mapping.txt.gz   <- version actual (versionCode 47)
    Segu-Luky-1.54s-mapping.txt.gz   <- historico (versionCode 46)
    Segu-Luky-1.53s-mapping.txt.gz   <- historico (versionCode 45)
    Segu-Luky-1.52s-mapping.txt.gz   <- historico (versionCode 44)
    Segu-Luky-1.51s-mapping.txt.gz   <- historico (versionCode 43)
    Segu-Luky-1.50s-mapping.txt.gz   <- historico (versionCode 42)
    Segu-Luky-1.49s-mapping.txt.gz   <- historico (versionCode 41)
    Segu-Luky-1.48s-mapping.txt.gz   <- historico (versionCode 40)
    Segu-Luky-1.47s-mapping.txt.gz   <- historico (versionCode 39)

Cada archivo solo sirve para las trazas del codigo con el que se genero.

Alcance (importante)
--------------------
Los nombres de clase se conservan (Kotlin objects con `INSTANCE`), pero los de
metodo y los numeros de linea se reescriben, y **eso** es lo que resuelve cada
archivo. Se corresponde con el codigo de su version, no con el binario publicado
byte a byte: Android no produce builds reproducibles, asi que el APK que se
distribuye tiene otro SHA-256. Sirve para simbolizar trazas del mismo codigo; si
se recompila con otro commit, hace falta su propio mapping.

Como usarlo
-----------
1. Descomprimir:
   `gzip -dk Segu-Luky-1.55s-mapping.txt.gz`
2. Con la traza ofuscada en `trace.txt`, ejecutar desde la raiz del SDK:
   `java -jar build-tools\35.0.0\lib\d8.jar retrace.jar mapping.txt trace.txt`
   o la tarea de Gradle `retrace` si esta disponible.
3. Se obtienen las clases y lineas originales.

Regla de mantenimiento
----------------------
Archivar un mapping por cada version publicada en `APK´s/mapping/`, con el
nombre de la version. Es la unica copia: `app/build/` esta ignorado por git y se
borra con `gradlew clean`.
